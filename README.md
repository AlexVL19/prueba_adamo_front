# Backend de prueba técnica de Desarrollador Junior - AdamoServices
Esto es la mitad de un proyecto de prueba técnica, siendo este el frontend desarrollado en React. Este proyecto pretende simular un módulo de inicio de sesión, en donde el usuario puede registrarse, iniciar sesión y cambiar su contraseña.

## Características principales
- El usuario puede registarse, especificando su nombre, apellido y correo electrónico.
- Se envía una contraseña provisional al correo electrónico del recién registrado.
- Al ingresar por primera vez, el sistema le solicitará al usuario una nueva contraseña.
- Se muestra un dashboard al final del flujo.

## Instalación y uso
Para utilizar el proyecto, sigue los siguientes pasos:

### Descargar el archivo .zip
Dicho archivo .zip se puede descargar desde el repositorio en GitHub.

### Entrar en el directorio del proyecto (desde consola)
cd prueba-adamo-front

### Instalar las dependencias desde consola
npm install

### Iniciar el servidor de desarrollo desde consola
npm run dev
